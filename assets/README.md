# Identidad de Sunú

Recursos aprobados en la conversación de diseño del 4 de octubre de 2026:

- `sunu-wordmark.png`: logo 03 · Acento, extracción raster con alfa usada en el borrador editorial aceptado. Se muestra como máscara CSS para conservar sus letras y adaptar el color al modo claro/oscuro. No es un vector.
- `sunu-icon-master.png`: original aprobado v3, 1254 × 1254, fondo marfil opaco, disco oliva circular, dos líneas concéntricas y monograma ú. No contiene el marco negro de la captura del usuario.
- `../icons/`: exportaciones deterministas del original a 180, 192 y 512 px. La variante maskable tiene margen marfil adicional para respetar el área segura de instalación; no cambia el dibujo aprobado.
- `fonts/`: Manrope variable y Cormorant Garamond 600, con licencias SIL Open Font License. Fuentes oficiales: https://github.com/google/fonts/tree/main/ofl/manrope y https://github.com/google/fonts/tree/main/ofl/cormorantgaramond.

Los logos se generaron previamente con Imagegen integrado. Esta implementación reutiliza las imágenes aprobadas; no genera una identidad nueva. Paleta clara: #F7F3E8, #3F4B36, #292822, #E7C66B y #A6563E.
